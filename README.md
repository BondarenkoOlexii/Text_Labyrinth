## 📌 Про проєкт

**Text Labyrinth** — це класична текстова гра в терміналі, розроблена для демонстрації роботи з двовимірними матрицями координат, валідацією користувацького введення та чистою модульною архітектурою класів без використання сторонніх фреймворків чи бібліотек.

---

## 🎮 Ігровий процес та особливості

* **Покрокова навігація:** Переміщення лабіринтом за напрямками (`W`, `A`, `S`, `D` або стрілки) у пошуках виходу.
* **Перевірка колізій:** Контроль меж карти, непереборних перешкод (стін) та тригерів досягнення цілі.
* **Динамічне оновлення консолі:** Покроковий рендеринг стану ігрового поля після кожного ходу.
* **Чистий Python (Zero Dependencies):** Працює «з коробки» на будь-якій системі зі стандартним інтерпретатором Python.

---

## 🏗 Архітектура класів (ООП)

* **`Player`:** Зберігає поточні координати $(x, y)$, стан гравця та логіку зміни позиції.
* **`Maze` / `Board`:** Відповідає за представлення двовимірної сітки лабіринту, валідацію доступності клітинок та точки старту/фінішу.
* **`GameEngine` / `Game`:** Керує головним ігровим циклом (Game Loop), обробкою введених команд та умовами перемоги/поразки.
